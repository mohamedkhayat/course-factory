# course-factory

The vocabulary of course-factory: an app that turns study material into interactive courses generated by local models.

## Language

**Course**:
Everything generated from one body of study material: an ordered list of Chapters, plus the Exams and Labs that sit beside them.
_Avoid_: module, class, subject

**Chapter**:
An ordered part of a Course, made of an ordered list of Sections.
_Avoid_: unit, lesson, milestone

**Section**:
An ordered part of a Chapter, made of an ordered list of Blocks.
_Avoid_: page, lesson, topic

**Block**:
One use of a Component inside a Section: which Component, its content as data that fits that Component's shape, and citations to the source pages. A Block holds no code and never contains another Block.
_Avoid_: widget, card, element

**Component**:
A reusable piece of course UI, such as a theorem box or a quiz, that declares the shape of content it accepts. Components are code; Blocks are data.
_Avoid_: widget, template

**Prose Block**:
The escape hatch: a Block of free Markdown with math, used when no Component fits the content.
_Avoid_: raw block, HTML block

**Citation**:
A pointer from a Block to an exact place in the source material: a file, a page, and optionally a short quote.
_Avoid_: reference, source link

**Origin**:
Whether a Block is From source (taken from the material, and must carry at least one Citation) or Model-added (written by the model, Citations optional, always marked as such).
_Avoid_: provenance (reserved for who made a Component)

**Exam**:
A timed paper at Course level: a title, a duration, the Chapters it covers, and an ordered list of Questions. It is either a Past paper or a Mock exam.
_Avoid_: test, quiz

**Past paper**:
An Exam rebuilt faithfully from a real exam in the material, with its correction taken from the corrigé.
_Avoid_: annale, old exam

**Mock exam**:
A new Exam the model writes in the style of the Past papers, covering the same recurring question types.
_Avoid_: practice test, sample exam

**Question**:
One item of an Exam: a statement, its points, a model answer, and optionally a Marking scheme.
_Avoid_: exercise (an exercise lives in a Section)

**Marking scheme**:
Which steps of a Question's answer earn which points, so a copy can be graded step by step.
_Avoid_: rubric, barème

**Lab**:
A coding exercise at Course level, usually from a TP, that lists the Chapters it covers.
_Avoid_: TP, notebook, Application Lab

**Generation Run**:
One pass of turning material into a Course, which pauses at Approval Gates and can resume after a stop.
_Avoid_: job, build, pipeline run

**Approval Gate**:
A point in a Generation Run where it waits for the owner to approve, edit or reject what was produced.
_Avoid_: checkpoint, review step

**Harness**:
Everything that shapes the local model's work apart from its weights: prompts, skills, tool guidance and checks. It is versioned as a whole.
_Avoid_: prompts, config

**Trace**:
The record of one model step: the Harness version, inputs, output, check results, and what the owner did with it.
_Avoid_: log, event

**Review Queue**:
The model-made Components (and later, flagged Blocks) waiting for Claude Code to promote, fix or reject them. Claude Code works the queue from outside the app; the app itself never calls Claude.
_Avoid_: backlog, inbox

**Live work**:
Model work the owner is waiting on right now, such as a tutor reply or grading a copy. It takes priority over a Generation Run for the GPU.
_Avoid_: interactive job, foreground task

## Relationships

- An **Approval** or rejection recorded on a **Trace** is both a signal and an eval case for improving the **Harness**.
